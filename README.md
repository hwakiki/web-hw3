## 어려웠던 점 3가지와 해결
 1. 하트 누를 때 상세 창까지 열리던 것: 카드 클릭 이벤트 안에서 .like 버튼이면 찜만 처리하고 바로 return하게 해서 겹치지 않게 고쳤습니다
 2. 새로고침하면 찜이 풀리던 것: liked 배열만 바꾸면 페이지 새로고침 때 사라져서 localStorage에 저장하고 불러오게 연결해서 해결했습니다
 3. 검색,필터,정렬 합치는 것: 조건을 getView() 한 곳에서 모아서 처리하고 refresh()로 화면만 다시 그리게 나눠서 정리했습니다
